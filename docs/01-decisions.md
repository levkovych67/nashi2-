# «Наші V2» — рішення та відкриті питання

Дата: 2026-11-17. Документ спільний для дизайн-команди і технічної команди. Він фіксує рішення, без яких команди не
можуть стартувати паралельно, і закриває кожне відкрите питання замовника **рішенням за замовчуванням**. Замовник може
змінити будь-яке з них; тоді змінюється цей файл, а плани читають його як джерело правди.

Позначки статусу:
- **ПРИЙНЯТО** — випливає з вимог або з аудиту V1, змінювати не плануємо.
- **ЗА ЗАМОВЧУВАННЯМ** — відкрите питання замовника, роботу ведемо з цим рішенням, підтвердження чекаємо.
- **БЛОКУЄ** — без відповіді замовника певна частина не може бути завершена (вказано яка).

Пов'язані документи: `00-v1-audit.md` (що беремо з V1), `02-contracts.md` (API, модель даних, токени дизайну,
формат handoff), `tasks/` (ТЗ командам), `plans/` (плани імплементації).
