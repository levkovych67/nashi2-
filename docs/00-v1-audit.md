# Аудит «Наші V1» і що з нього бере V2

Дата: 2026-11-17. Джерела: код `nashi-backend/` і `nashi-frontend/`, їхні `CLAUDE.md`, `DESIGN_SYSTEM.md`,
специфікації в `docs/superpowers/`, `RELEASE.md`, вихід dry-run імпорту з Вікіпедії
(`nashi-backend/build/wiki-dry-run.json`). Документ закриває критерій приймання «V1 проаналізовано, а повторно
використані технології та компоненти задокументовано» і є вхідним матеріалом для обох команд.

## 1. Що таке V1

Геокультурний атлас України: карта з митцями чотирьох типів (музиканти, гурти, художники, письменники) та подіями,
плюс сторінки новин, радіо (мікси демо-треків за регіоном), список митців, форми пропозиції митця і події.

| | Backend | Frontend |
|---|---|---|
| Репозиторій | `nashi-backend` (окремий git) | `nashi-frontend` (окремий git, публічний) |
| Стек | Java 17, Spring Boot 3.4.1, MongoDB, Spring AI (OpenAI), AWS S3, telegrambots 8.2, MapStruct, Lombok, Gson | React 19, TS 5.9, Vite 7, TanStack Query 5, Zustand 5, react-map-gl 8 + MapLibre 5, supercluster, React Hook Form + Zod, Tailwind 3 + shadcn/Radix, Howler |
| Обсяг коду | ≈14,5 тис. рядків Java (разом з тестами), з них більшість — імпорт з Вікіпедії | ≈9,6 тис. рядків TS/TSX |
| Тести | JUnit 5 + Mockito без Spring-контексту (свідома заборона: контекст міг дістатися бойових сервісів) | `node:test` для чистих хелперів |
| Деплой | GitHub Actions → SSH на VPS → `git pull`, `gradlew build`, `systemctl restart` | GitHub Actions → збірка → VPS, nginx |
| Секрети | файл `/etc/nashi/nashi-backend.properties` поза репо + `StartupConfigGuard` | `.env.local` (лише ключ MapTiler) |

  - основа місця: народження — 3184, заснування гурту — 474, проживання/робота — 8;

  - посилання на стрімінги/відео: YouTube 474, Spotify 325, Deezer 295, Apple Music 277, SoundCloud 280, Bandcamp 84.
- Розподіл за регіонами (музиканти): Київщина разом з Києвом — 737 (з них місто Київ — 604), Львівщина — 487,
  Харківщина — 265, Одещина — 191, Івано-Франківщина — 166, Тернопільщина — 165 … Херсонщина — 42, Миколаївщина — 40.
- Різних населених пунктів: 1065. Найбільші: Київ 604, Львів 273, Харків 207, Одеса 150, Дніпро 68.

Висновки для V2:
1. **Звук на старті є в меншості музикантів** (≤ 10 % мають ID Deezer/Apple). Більшість — історичні постаті.
   Тому джерела аудіо мають бути кількома (D-20), а дизайн мусить мати стан «без фрагмента» (D-27).
2. **Щільність у великих містах величезна** (Київ — 604 в одній точці). У V1 вони стояли в одній точці стосом зі
   списком на сотні рядків. У V2 — розкид пінів у межах міста (D-13) і рівень «населені пункти» (D-12).
3. **Фото є лише в третини** — пін і картка мусять гарно виглядати без фото (ініціал/символ).

## 5. Уроки V1, які V2 враховує

1. Локальний запуск з бойовими налаштуваннями «крав» оновлення бойового Telegram-бота → long polling лише в production (D-65), guard на профілі.
2. Контрольований `viewState` карти ламав кліки по кластерах → лише неконтрольована камера (D-16).
3. Сотні людей в одній точці → розкид пінів і рівень населених пунктів (D-12, D-13).
4. Координати міст від AI → довідник із Вікіданих.
5. Telegram-повідомлення з сирим JSON і невідповіданий callback (крутилка на кнопці) → читабельна картка, `answerCallbackQuery`, редагування повідомлення.
6. Відхилена заявка видалялася безслідно → історія заявок і дій.
7. Документація розходилась з кодом (спіраль колізій, асинхронна обробка) → contract-first і тести відповідності.
8. Київ злитий з Київською областю → 27 регіонів (D-11).
9. Ліміт 100 МБ і фото з EXIF-геоданими телефона → 10 МБ, перекодування, видалення EXIF.

## 6. UX V1 — що варто знати дизайн-команді

- Карта на весь екран — головна сторінка; desktop: скляна панель фільтрів 360 px зліва зі списком результатів;
  mobile: смуга внизу («Фільтри (n)», «Список») і нижні шторки.
- Пін — фото митця у скляному кільці; кластер — аква-бульбашка з числом; однакові координати — стос зі списком.
- Картка-прев'ю: типи, жанри, місто, рік, «Переглянути профіль»; посилання `/?artist=<slug>` відкриває митця на карті.
- Сторінка митця: шапка з фото, факти (дати, місце), «Слухати» (вбудовані плеєри), твори, посилання, атрибуція Вікіпедії.
- Немає: лайків, звуку на карті, пояснення про геомітку, фільтра «населений пункт»; багато розділів (події, новини, радіо)
  розпорошують увагу на телефоні.
- Стиль Frutiger Aero — яскравий і впізнаваний, але важкий (скло, блюр, анімації) для слабких телефонів.
