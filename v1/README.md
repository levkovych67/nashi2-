Тут лежить код «Наші V1» станом на момент створення репозиторію V2. Це **референс**: з нього V2 переносить
рішення (імпорт з Вікіпедії, правила виключення, геодані), а технічна команда звіряється з ним при міграції даних.

репозиторіях. Історію бекенду сюди не перенесено свідомо: у ранніх комітах були робочі ключі доступу.

Що з V1 беремо, адаптуємо чи прибираємо — `docs/00-v1-audit.md`.
