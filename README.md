# Наші V2

Інтерактивна карта України з музикантами: де вони народилися чи де заснувалися гурти, випадкові фрагменти їхніх
творів просто з карти, сторінки музикантів, необмежені лайки і пропозиція нових музикантів з модерацією в
Telegram-групі. Фаза 1 — лише музиканти; mobile-first, desktop підтримується.

V2 будується на основі аналізу V1. Знімок коду V1 лежить у `v1/` (див. `v1/README.md`); робочі репозиторії V1
(`nashi-backend`, `nashi-frontend`) лишаються в експлуатації до перемикання.

## Структура репозиторію (цільова)

```
nashi_v2/
  docs/          документи вище; docs/adr/ — архітектурні рішення, що з'являтимуться в роботі
  contracts/     openapi.yaml, fixtures/, geo/, scripts/ — спільне для обох команд
  studio/        платформа-студія дизайн-команди (Vite + React)
  web/           продукт: React SPA (core/ — логіка, ui/ — скін)
  backend/       продукт: Spring Boot (Java 21), MongoDB, S3, Telegram, імпорт з Вікіпедії
  infra/         Docker Compose, nginx, GitHub Actions
  v1/            знімок V1 (backend, frontend) — лише для довідки
```

## Як команди працюють паралельно

```
тиждень        1        2        3        4        5        6   …   10–11
студія   [каркас+фікстури][айдентика+варіанти][сценарії+погодження][handoff]
продукт  [контракт+backend каркас][карта, піни, лайки, заявки, Telegram, Вікіпедія, аудіо][каркасний UI]…[дизайн з handoff][реліз]
                     ▲                                              ▲
            02-contracts.md — єдина точка синхронізації      studio/handoff/ → web/src/design/
```

Дизайн-команда не чекає на backend (студія працює на фікстурах тієї ж форми, що й API). Технічна команда не чекає на
дизайн (логіка в `web/src/core/` не залежить від скіну; каркасний UI замінюється після handoff).

## Як запустити

Потрібен Node.js 24 (`.nvmrc`).

```bash
npm install            # залежності всіх workspace-ів (contracts, web, studio)
npm test               # тести в усіх workspace-ах
npm run lint:api       # лінт contracts/openapi.yaml (Redocly)
npm run dev -w studio  # дизайн-студія на http://127.0.0.1:5173

VITE_API_MOCK=1 npm run dev -w web     # продукт на http://127.0.0.1:5174 на фікстурах, без backend
infra/scripts/local-up.sh              # backend у Docker на http://127.0.0.1:8081 (mongo, minio)
npm run dev -w web                     # продукт проти цього backend (проксі /api)
npm run e2e -w web                     # Playwright; порт 5174 має бути вільним
npm run build -w web && npm run check:bundle -w web   # продакшен-збірка і бюджети
infra/scripts/local-up.sh --with-web   # backend і web (nginx) у Docker, web на http://127.0.0.1:4175
```

Подробиці: [web/README.md](web/README.md) (змінні, e2e, візуальні еталони, дизайн, Lighthouse) ·
[infra/LOCAL.md](infra/LOCAL.md) (локальний стек, порти, перевірка web).


Контракт API — `contracts/openapi.yaml` (опис і тест-вектори: `contracts/README.md`). Рішення щодо версій і
архітектури — `docs/adr/`.

## Дизайн-студія

У каталозі можна порівняти всі 17 рішень, відкрити кожен варіант на весь екран і переглянути його на телефоні за QR-кодом. Чотири напрями айдентики мають власні логотипи, шрифти, палітри та зразки оформлення. Розділ «Сценарії» з’єднує вибрані варіанти в пошук музиканта на карті й подання заявки. «Стани» показують, як інтерфейс реагує на збої, порожні результати й повторні дії.

«Моя чернетка» зберігає вибір у браузері. На сторінці «Передача» можна зафіксувати окремі погодження і завантажити файл рішень. Генератор пакета для технічної команди входить до студії.
