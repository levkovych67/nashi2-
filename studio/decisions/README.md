# Погодження дизайну

У каталозі оберіть варіанти, відкрийте їх на телефоні та великому екрані й пройдіть обидва сценарії. Вкладка «Передача» об’єднує вибір цього браузера з поточним файлом студії. Для кожного з 17 рішень без вибору вона показує початковий варіант зі статусом `PROPOSED`.

Відповідальна особа позначає переглянуті рішення, вводить ім’я або роль, додає посилання на протокол і підтверджує погодження. Кнопка «Затвердити позначені рішення» зберігає дату та автора у цьому браузері. Зміна варіанта або його параметрів потребує нового погодження.

Кнопка «Завантажити decisions.json» експортує поточні статуси. Дизайн-лід звіряє автора та дату з протоколом у `sessions/`, відкриває PR до `studio/decisions/decisions.json` і передає його учасникам на перевірку. Погодження вважається зафіксованим у репозиторії після злиття PR. Шаблон для кожної зустрічі міститься у [sessions/TEMPLATE.md](sessions/TEMPLATE.md).

## Збірка пакета

З кореня репозиторію виконайте:

```sh
npm ci
npx playwright install chromium
npm run handoff -w studio
```

Генератор перевіряє формат рішень, доступність обраних варіантів, токени, контраст, українські тексти та ліцензії шрифтів. Для знімків він запускає локальну студію, відкриває 17 обраних варіантів та проходить обидва сценарії у Chromium з розмірами 390 × 844 і 1440 × 900. Результат з’являється у `studio/handoff/` після успішної перевірки всіх артефактів. Для вже запущеної локальної студії можна вказати адресу у `HANDOFF_STUDIO_URL`. Для встановленого системного Chromium можна задати `PLAYWRIGHT_CHROMIUM_EXECUTABLE`, для власного локального сеансу віддаленого налагодження — `HANDOFF_LOCAL_CDP`.

Для проміжної перевірки даних виконайте `npm run handoff -w studio -- --no-screens`. Відкрийте `HANDOFF.md` та звірте статуси й відмінності від початкових рішень. Технічна команда застосовує лише `APPROVED`. Файл із пропозиціями можна обговорювати та перевипускати під час роботи.

Для остаточної передачі відповідальні учасники перевіряють усі 17 погоджень, обидва сценарії та комплект знімків. Дизайн-лід додає пакет і протокол до PR. Зміни після передачі проходять нове погодження з описом впливу на продукт.
