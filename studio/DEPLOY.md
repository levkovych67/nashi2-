# Локальний перегляд студії

Потрібні Node 24 і npm. Виконайте з кореня робочої копії `nashi_v2/`.

```sh
npm ci
npm run dev -w studio
```

Каталог відкривається за адресою, яку друкує Vite. Готові порівняння доступні на `/d/identity`, `/d/map.pin` і `/d/map.cluster`. На сторінці порівняння можна обрати варіант, змінити розмір екрана, відкрити повноекранний прототип та його QR-код. «Моя чернетка» зберігає вибір у браузері та експортує його в посилання або JSON. Дані вже входять у contracts/fixtures.

## Перевірки

```sh
npm test -w contracts
npm run lint -w studio
npm run typecheck -w studio
npm test -w studio
npm run build -w studio
npx playwright install chromium webkit
npm run e2e -w studio
```

## Приватне демо на телефоні

Для спільного перегляду потрібна доступна з телефону HTTPS-адреса. QR-код використовує адресу відкритої студії. Якщо відкрити її як localhost, телефон теж отримає localhost.

Результат `npm run build -w studio` міститься в `studio/dist/`. На сервері HTTPS для окремого домену підключається [конфігурація nginx](../infra/nginx/studio.conf). Облікові дані Basic Auth зберігаються на сервері в `/etc/nginx/nashi-studio.htpasswd`. Після розгортання перевірте відповідь 401 без пароля на каталог, JSON і WAV, а після входу — сторінку порівняння, атрибуцію та відтворення з телефона. Автоматизація в репозиторії запускає перевірки при змінах студії або контрактів. Публікація потребує адреси сервера й налаштованого доступу.
